# Synthetic examples

Every row was generated by the packaged equations. No participant records are included. The manifest records generator names, seeds, sample counts and file hashes. These small files demonstrate formats and are not the full training populations.

Clinical CSVs contain predictors followed by a binary outcome. Brain and protein NPZ keys are described in their family READMEs. The label-free NPY matrix has 256 rows and 201 measurements; its adjacent columns file gives ordered Field IDs. The rare-risk predictors CSV contains the 38 documented conditioning measurements, and the probabilities CSV gives fixed-model 15-year risks for hyperparathyroidism. Those probabilities are not labels or clinically calibrated estimates.

Regenerate the examples from the repository root:

    python examples/regenerate.py
