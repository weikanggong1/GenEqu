# Dictionary-only 15-year population and risk model

This executable model defines a hypothetical baseline population and a future binary
event for each requested disease. Every numerical distribution, loading, intercept,
coefficient and missingness mechanism is an author-specified modeling assumption.
Dictionary limits and permitted codes constrain the interface; they do not estimate
population distributions. No participant records, marginal quantiles, observed disease
frequencies, empirical disease effects, test outcomes or performance were used.
No classifier is fitted, and no language model or pretrained predictor runs at sampling
or prediction time. The model is not an externally calibrated clinical risk calculator.

## Execution and files

Requirements: Python 3, numpy, pandas and scipy. Tested with numpy 1.26.4,
pandas 2.2.3 and scipy 1.14.1. Standard-library unittest runs the tests.

```bash
python generate.py --schema measurement_dictionary.csv \
  --disease-identities disease_identities.csv --output-dir generated_run \
  --n 360000 --seed 20260831 --diseases E4_HYPERPARA K11_COELIAC
python test_model.py
```

The output directory must not exist. Each file is named
`synthetic_<CODE>_<N>.csv`; the first 201 columns exactly follow the dictionary's
Field_ID order and the final column is the disease code, containing 0/1. There is
one independent population per disease. `n` is rows per disease, not a total split
over diseases. A final `audit.json` records source/input hashes, seeds, per-disease
row and class counts, missing counts and output SHA-256 hashes. Its status becomes
`complete` only after all requested files have been written and hashed.

```python
from model import generate
from predict import predict_risk
table = generate('measurement_dictionary.csv', 'E4_HYPERPARA', 1000, 20260831)
X = table.iloc[:, :201].to_numpy()
p = predict_risk(X, list(table.columns[:201]), 'E4_HYPERPARA')
```

`predict_risk(X, feature_names, disease)` returns an N-vector in [0,1]. It accepts
numeric arrays, NaN and string Field_IDs, including the full ordered 201-field
interface or an explicitly named subset. Unknown names, including outcome columns,
are rejected. Empty batches are accepted. Internal and external chunk sizes and row
ordering do not change the equations. There is no batch-dependent centering,
standardization, prior estimation or threshold estimation.

The `predict.py --input predictors.csv --disease CODE --output new_risks.csv` CLI
accepts predictors only, rejects existing output files, and writes continuous
probabilities. Strip the synthetic outcome column before using this CLI.

## Population and causal order

Seventeen baseline factors Z are mutually independent N(0,1). Binary sex S is an
independent Bernoulli(0.5), with the model convention 0=female and 1=male. These are
population assumptions. Every observation-specific N and every event error is an
independent standard normal unless an equation explicitly reuses a shared value.
Uniform, beta, Poisson and binomial draws in the field table are independent
conditional on their displayed factors. Baseline measurements are generated by
`population_block(schema,n,rng)`, which has no disease argument. Disease labels are
sampled only after the entire baseline table is complete. No outcome, future-event
probability or future-event error enters a measurement or its missingness pattern.
The shared factors describe baseline susceptibility, not hidden disease diagnoses.

Baseline age is `39 + 31 Phi(Z_age)`, producing a continuous uniform distribution
over the supplied age support. This distribution is assumed, not estimated.
Continuous fields retain sufficient floating precision to preserve algebraic
identities. The dictionary's recommended decimal places are reporting suggestions;
only categorical, binary and bounded-count fields are rounded to integers.

## Observation equations used by the predictor

For each continuous observation j below, let
`U_j = l_j' Z + delta_j S + sigma_j epsilon_j`.
For linear-unit observations define L=low, H=high, C=center. For log-unit
observations define L=log(low), H=log(high), C=log(center).
Set `r=(C-L)/(H-L)`, `a=logit(r)`,
`k=dispersion/((H-L) r (1-r))`, and
`V_j = L+(H-L) sigmoid(a+k U_j)`.
The reported measurement is V for linear-unit rows and exp(V) for log-unit rows.
Thus center is the value at U=0, not a population mean; dispersion is the local
derivative in the transformed units at U=0, not a fitted standard deviation.
The units are those in the dictionary. Supports narrower than the dictionary are
deliberate physical-coherence assumptions, particularly for RBC, MCV and MCHC.

For an interior observed value x, the exact inverse is
`U_j=[logit((g(x)-L)/(H-L))-a]/k`, where g is identity or log.
The predictor uses the table below, age, sex and pack years only. All other fields
are still generated and documented but are excluded from its conditioning set.
This is a declared subset approximation: it estimates P(Y|selected measurements),
not the full P(Y|all 201 fields). Excluded fields can be informative through shared
causes. In particular, ordinal skin-color and sleep codes are not interpreted by
the predictor because the input dictionary does not supply complete code labels.

Pack years has a distinct zero-censored observation:
`W=Z_smoking+0.55 epsilon`, and
`pack=clip(exp(2.2) expm1(0.75 W),0,222)`.
A positive interior pack value inverts exactly to
`W=log1p(pack/exp(2.2))/0.75`. Zero means W<=0; 222 means
`W>=log1p(222/exp(2.2))/0.75`.
The smoking status and tobacco-report fields reuse W, so a never-smoker has zero
pack years. A current/former classification is generated conditionally on W and age.

## Measurement-to-risk inference

Condition on observed age by fixing Z_age to `Phi^-1((age-39)/31)`, leaving its
conditional variance zero. When age is missing it remains N(0,1). Exact boundary
ages 39 and 70 are evaluated at CDF probabilities 1e-10 and 1-1e-10; this is a
documented finite limiting approximation for externally rounded endpoint ages.
Age outside the allowed support is treated as missing. Observed sex selects one
sex component; missing/invalid sex is marginalized over both components with prior
weights 0.5. Its posterior mixture weights include the available observation
likelihoods and smoking-censoring likelihood, so it is not simply imputed.

For available uncensored Gaussian observations, write r=y-delta*S-L*m0,
where m0 contains the known age factor if any. On the remaining free factors,
`C=(I+L' R^-1 L)^-1` and `m=C L' R^-1 r`, with
`R=diag(sigma_j^2)`. Restore the known age component to m and zero age variance
in C. Missing Gaussian observations contribute no likelihood term. Neither their
values nor factor means are filled into the event equation as known observations.
The Gaussian marginal likelihood is evaluated by the determinant lemma and
Woodbury identity to update the sex mixture.

For disease d and a sex component, future occurrence is
`Y_d=1{a_d+c_d*S+b_d'Z+epsilon_d>0}`, with independent `epsilon_d~N(0,1)`.
Its horizon is 15 years. Given a Gaussian posterior, the exact integrated risk is
`Phi((a_d+c_d*S+b_d'm)/sqrt(1+b_d'C b_d))`.
The denominator retains irreducible event noise and unobserved-factor uncertainty.
Endometriosis additionally sets Y=0 and risk=0 for S=1 under the declared anatomy
assumption. There is no rejection sampling, forced class balance or class separation.

For a zero or capped pack value, after conditioning on other measurements let
`mu_W=m_smoking`, `v_W=C_smoking,smoking+0.55^2`,
`mu_E=a+c*S+b'm`, `v_E=1+b'Cb`, and `c_EW=b'C[:,smoking]`.
For a standardized W value t, conditional risk equals
`Phi((mu_E+c_EW*t/sqrt(v_W))/sqrt(v_E-c_EW^2/v_W))`.
Integrate this expression over the appropriate truncated standard normal interval.
The implementation uses a fixed 48-node Gauss-Legendre rule on its CDF interval,
and its interval probability enters the sex-mixture likelihood. This is the only
routine numerical integration approximation. Tail probabilities are floored at
1e-14 and inverse-CDF arguments at [1e-15,1-1e-15] for finite arithmetic. Tests compare
the result with independent adaptive integration for both censoring directions.

With all measurements missing, the result is the explicit prior average:
`0.5 sum_{s=0,1} Phi((a+c*s)/sqrt(1+sum(b^2)))`, omitting the male contribution
for endometriosis. No empirical outcome rate is substituted.

Non-finite or out-of-support continuous predictor values are marginalized as missing.
Gaussian observations exactly at a transform support endpoint are also omitted,
since the inverse transform is infinite; this policy can discard boundary information
in externally censored measurements. Pack-year boundary observations use the
explicit censoring integration instead. Returned probabilities never use external
labels or outcome counts.

## Units, constraints, categorical assumptions and missingness

Every final value is clipped to the dictionary hard bounds. The generation formulas
restrict key algebraic constituents so the following relationships hold before CSV
rounding: weight=BMI*height_m^2; weight=fat_mass+fat_free_mass; regional fat percentages
match regional masses; regional mass sums leave an unreported residual body region;
white-cell subtype counts sum to WBC and subtype percentages sum to 100;
haematocrit=RBC*MCV/10; haemoglobin=RBC*MCV*MCHC/1000; MCH=MCV*MCHC/100;
plateletcrit=platelets*MPV/10000. FEV1<=FVC and systolic>diastolic. The spirometry
ratio Z score is an internal reference definition with assumed age-dependent mean
and scale, not an external clinical reference equation. Total cholesterol is a
bounded reporting approximation to LDL+HDL+0.45*triglycerides. Total protein is
albumin plus a bounded globulin component, subject to dictionary reporting bounds.
Unrounded component identities have dedicated tests; CSV uses nine significant digits.

The dictionary lists permitted category numbers without their complete code labels.
Ordinal equations are therefore explicit synthetic ordering conventions, not a
claim that every code's external UKB meaning was verified. Uniform normal-score
thresholds `Phi^-1(k/K)` divide a latent score into K ordered allowed codes.
Field 6144 is represented by one nominal response code, not simultaneous exclusions.
Smoking and alcohol status use the explicitly stated conventions in the field table.
Values outside an activity category's intended external semantics would require a
separate code dictionary; no unavailable labels were retrieved during construction.

The sole missingness mechanism is parental survival: potential current parental age
is participant age plus a generation offset and noise; an independent sampled death
age determines whether current parental age or age at death is reported. Exactly
one of each parent's current-age/death-age pair is missing. This is baseline
structural missingness, never a function of the future target. All other fields are
complete by assumption. No real missingness proportion has been estimated.

The 15 diseases are modeled separately and are not a competing-risks or recurrent
event system. The 15-year horizon is encoded in each direct event equation; death,
diagnosis timing and competing events are not simulated. The disease names containing
EXALLC identify the requested disease only: exclusion of other cancers from control
groups cannot be implemented from the supplied identities and is not claimed.
No prevalent target-specific diagnosis is generated or used to screen baseline rows;
the outcome is an assumed future event in a hypothetical at-risk population, not a
validated incident registry phenotype.

## Assumed factors

- **age**: Older baseline age: age in years = 39 + 31 Phi(Z_age).
- **adiposity**: Greater adiposity propensity, shared by BMI and metabolic measurements.
- **smoking**: Greater cumulative tobacco exposure propensity, with a zero-exposure hurdle.
- **alcohol**: Greater alcohol exposure propensity, including unmeasured long-term exposure.
- **activity**: More physical activity and physical capacity.
- **anxiety**: Greater baseline anxious arousal, independent of future phobic-anxiety labels.
- **inflammation**: Greater baseline systemic inflammatory propensity.
- **renal**: Lower baseline renal filtration propensity.
- **calcium**: Higher baseline circulating-calcium propensity, not a diagnosed endocrine state.
- **immune**: Greater baseline autoimmune/immune activation propensity.
- **lipids**: More atherogenic circulating lipid propensity.
- **glycemia**: Higher baseline glycemic propensity.
- **pigmentation**: Fairer, more UV-sensitive constitutive pigmentation propensity.
- **uv**: Greater cumulative ultraviolet exposure propensity.
- **reproduction**: Greater estrogen-related reproductive exposure propensity.
- **education**: Longer educational attainment propensity.
- **sleep**: Poorer sleep quality propensity.

## Disease event equations and rationale

Every listed coefficient is an assumption in probit-score units per factor SD; a male shift is per code 1 versus 0. All unlisted coefficients are zero. Intercepts are illustrative horizon assumptions, not observed 15-year incidences.

### E4_HYPERPARA: Hyperparathyroidism

`E = -2.8 -0.18 S +0.35 Z_age +0.8 Z_calcium +0.25 Z_renal + epsilon`, `epsilon ~ N(0,1)`.

Calcium is the main endocrine clue; age, female sex and impaired filtration provide context. The endpoint includes heterogeneous primary and secondary forms, represented by one illustrative equation.

### F5_PHOBANX: Phobic anxiety disorders

`E = -2.8 -0.15 S -0.12 Z_age +0.85 Z_anxiety +0.25 Z_sleep -0.08 Z_education + epsilon`, `epsilon ~ N(0,1)`.

Anxious arousal and disturbed sleep represent susceptibility; sex, age and educational context have smaller assumed contributions. Pulse and sleep reports are nonspecific baseline correlates.

### K11_COELIAC: Coeliac disease

`E = -3 -0.1 S +0.85 Z_immune -0.08 Z_age + epsilon`, `epsilon ~ N(0,1)`.

Immune susceptibility links future diagnosis to hematological and nutritional measurements. Female sex and younger baseline age have small assumed shifts. Gluten exposure and inherited HLA effects remain unmeasured event uncertainty.

### F5_ALCOHOL_DEPENDENCE: Alcohol dependence

`E = -2.8 +0.3 S -0.12 Z_age +0.9 Z_alcohol +0.25 Z_anxiety +0.18 Z_smoking -0.12 Z_education + epsilon`, `epsilon ~ N(0,1)`.

Alcohol exposure dominates; smoking, anxious arousal, age, sex and education represent shared behavioral context. A current drinking quantity is an imperfect marker of long-term vulnerability.

### I9_ABAORTANEUR: Abdominal aortic aneurysm (AAA)

`E = -3.4 +0.6 S +0.7 Z_age +0.75 Z_smoking +0.2 Z_lipids +0.12 Z_inflammation + epsilon`, `epsilon ~ N(0,1)`.

Age, male sex and cumulative tobacco exposure dominate; atherogenic lipids and inflammation have smaller assumed roles. No aneurysm diameter or prevalent aneurysm label is generated.

### K11_ACUTPANC: Acute pancreatitis

`E = -3.1 +0.08 S +0.12 Z_age +0.65 Z_alcohol +0.25 Z_lipids +0.25 Z_adiposity +0.18 Z_calcium +0.2 Z_smoking + epsilon`, `epsilon ~ N(0,1)`.

Alcohol, adiposity and lipids represent several common etiological pathways; calcium and tobacco exposure contribute. Gallstone and medication pathways are absorbed in unobserved event noise.

### F5_ALZHDEMENT: Dementia in Alzheimer disease

`E = -3.6 -0.05 S +1.05 Z_age -0.3 Z_education -0.18 Z_activity +0.16 Z_glycemia +0.12 Z_smoking + epsilon`, `epsilon ~ N(0,1)`.

Age is the main driver across the 15-year window; education and activity represent reserve-related context, with smaller glycemic and smoking contributions. Cognitive tests, genotype and preclinical pathology are unmeasured.

### K11_ULCER: Ulcerative colitis

`E = -3 +0 S +0.75 Z_immune +0.25 Z_inflammation -0.08 Z_age -0.12 Z_smoking + epsilon`, `epsilon ~ N(0,1)`.

Immune and inflammatory propensity dominate. A weak inverse cumulative-smoking term is an explicit coarse assumption for a disease with smoking-state-specific associations; it is not a causal treatment claim.

### I9_CARDMYO: Cardiomyopathy

`E = -3.1 +0.25 S +0.3 Z_age +0.5 Z_alcohol +0.22 Z_adiposity +0.2 Z_inflammation +0.12 Z_renal + epsilon`, `epsilon ~ N(0,1)`.

Alcohol, age, adiposity, inflammation and filtration context represent heterogeneous cardiac susceptibility. Genetic and structural cardiac causes remain unmeasured.

### C3_NONHODGKIN_EXALLC: Non-Hodgkin lymphoma, all, excluding all cancers (controls excluding all cancers)

`E = -3.2 +0.15 S +0.55 Z_age +0.45 Z_immune +0.2 Z_inflammation + epsilon`, `epsilon ~ N(0,1)`.

Age, immune activation, inflammation and male sex describe broad susceptibility. The specific lymphoma subtypes and treatment-related causes are not distinguished.

### M13_POLYMYALGIA: Polymyalgia rheumatica

`E = -3.4 -0.15 S +0.85 Z_age +0.35 Z_immune +0.5 Z_inflammation + epsilon`, `epsilon ~ N(0,1)`.

Older age, inflammatory propensity, immune activation and female sex drive the illustrative equation. Inflammation is a nonspecific baseline risk correlate, not a contemporaneous disease label.

### C3_MELANOMA_SKIN_EXALLC: Malignant melanoma of skin, excluding all cancers (controls excluding all cancers)

`E = -3 +0.1 S +0.25 Z_age +0.55 Z_pigmentation +0.6 Z_uv + epsilon`, `epsilon ~ N(0,1)`.

Constitutive UV sensitivity, UV exposure and age drive risk. Vitamin D is only a noisy shared-exposure observation; it is not assigned a protective causal coefficient.

### N14_ENDOMETRIOSIS: Endometriosis

`E = -3 +0 S -0.65 Z_age +0.75 Z_reproduction +0.2 Z_inflammation + epsilon`, `epsilon ~ N(0,1)`.

Risk is zero for the modeled male anatomical category. Within female category, younger baseline age, reproductive exposure and inflammation affect future recorded occurrence. The binary sex interface cannot represent anatomy, gender diversity or prior surgery.

### C3_BLADDER_EXALLC: Malignant neoplasm of bladder, excluding all cancers (controls excluding all cancers)

`E = -3.5 +0.5 S +0.65 Z_age +0.75 Z_smoking + epsilon`, `epsilon ~ N(0,1)`.

Cumulative tobacco exposure, age and male sex dominate. Occupational carcinogen and inherited effects are unmeasured.

### M13_FIBROMYALGIA: Fibromyalgia

`E = -2.8 -0.35 S +0.5 Z_anxiety +0.65 Z_sleep -0.22 Z_activity +0.18 Z_adiposity + epsilon`, `epsilon ~ N(0,1)`.

Sleep disturbance, anxious arousal, lower activity, adiposity and female sex represent nonspecific susceptibility. No pain score or fibromyalgia-specific latent diagnosis is used.

## Relationship table and verification

`feature_disease_rules.csv` contains all 201 x 15 = 3,015 pairs. Direct relationships apply only to observed age and sex. Other non-neutral relationships are shared-factor associations, not estimated causal effects. Neutral means no active shared factor or direct risk term in this authored model, not proof of biological independence. The table records each path and whether it is used by the predictor. Each disease equation leaves substantial independent event uncertainty.

`test_model.py` checks determinism, field ordering, valid categories and bounds, structural missingness, algebraic identities, independent disease populations, all-missing prior risks, both smoking censoring integrals against adaptive quadrature, risk monotonicity, the sex gate, predictor batching and permutation, and rejection of outcome columns and non-dictionary input reads. These are synthetic correctness checks; they do not establish empirical calibration, discrimination or clinical validity. No full-size generation or real-data evaluation was performed during construction.
